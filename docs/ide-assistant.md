# CodeGuardian IDE Assistant

## Purpose

CodeGuardian IDE Assistant is a local MVP for consuming validated CodeGuardian suggestions without opening Bitbucket. It does not replace the Jenkins, SonarQube or Bitbucket workflow. The normal CI/CD flow still detects, generates, validates and publishes comments as before.

The assistant uses a local JSON export generated by the agent and provides two developer-facing tools:

- `tools/codeguardian_cli.py` for listing, validating and applying suggestions from a terminal,
- `ide/vscode-codeguardian` for viewing, previewing and applying suggestions inside VS Code.

---

## Results File

The agent writes the results file only when this environment variable is set:

```bash
CODEGUARDIAN_RESULTS_PATH=codeguardian-results.json
```

If the variable is missing, no results file is generated.

The file contains only final suggestions that survived normalization and patch validation. It includes repository metadata, summary counters, stable suggestion IDs, the original code, the proposed code and a content hash. It does not include credentials, API tokens or internal authentication data.

---

## CLI Usage

List all suggestions:

```bash
python tools/codeguardian_cli.py list --file codeguardian-results.json
```

Filter suggestions:

```bash
python tools/codeguardian_cli.py list --file codeguardian-results.json --source sonarqube --severity CRITICAL
python tools/codeguardian_cli.py list --file codeguardian-results.json --current-file src/main/java/App.java
```

Show one suggestion:

```bash
python tools/codeguardian_cli.py show --file codeguardian-results.json --id <suggestion_id>
```

Validate one suggestion against the current local file:

```bash
python tools/codeguardian_cli.py validate --file codeguardian-results.json --id <suggestion_id>
```

Apply one suggestion:

```bash
python tools/codeguardian_cli.py apply --file codeguardian-results.json --id <suggestion_id>
```

Apply several suggestions:

```bash
python tools/codeguardian_cli.py apply-selected --file codeguardian-results.json --ids id1,id2,id3
```

The CLI applies multiple suggestions from bottom to top inside each file to reduce line-shift problems.

## VS Code Extension

The extension lives in:

```text
ide/vscode-codeguardian
```

Development setup:

```bash
cd ide/vscode-codeguardian
npm install
npm run compile
```

Then open the extension folder in VS Code and run an Extension Development Host.

The extension contributes a `CodeGuardian Suggestions` tree view. It reads the configured results file from the current workspace root, groups suggestions by file and supports:

- refresh suggestions,
- open the affected file and line,
- preview original and proposed code,
- apply one selected suggestion,
- apply multiple selected suggestions.

The extension calls the Python CLI for application so that local patch safety has one source of truth.

---

## Configuration

VS Code settings:

| Setting | Default | Purpose |
| --- | --- | --- |
| `codeguardian.resultsFile` | `codeguardian-results.json` | Results JSON path relative to the workspace root |
| `codeguardian.pythonPath` | `python` | Python executable used to run the CLI |
| `codeguardian.cliPath` | `tools/codeguardian_cli.py` | CLI path relative to the workspace root |

If `python` is unavailable, the extension tries `python3`.

---

## Safety Rule

The IDE assistant never applies a suggestion automatically.

Before applying a suggestion, the CLI checks that `original_code` still matches the current local file content in the expected line range. If the file has changed or the range no longer matches, the suggestion is skipped.

Required imports are printed or displayed, but they are not inserted automatically unless they are already part of the `original_code` and `proposed_code` replacement block.

---

## Limitations

- The assistant reads a local JSON file only.
- It does not fetch comments from Bitbucket.
- It does not call Jenkins, SonarQube or Gemini.
- It does not stage, commit, push or modify Git state.
- It does not automatically insert imports outside the replacement block.
- It is an MVP VS Code extension, not a full review platform.
- It is not a replacement for compilation, tests, profiling or benchmarks.
