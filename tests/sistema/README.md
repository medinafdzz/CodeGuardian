# Nivel de sistema

Este nivel se valida mediante una ejecucion completa sobre el repositorio
`sample-mixed` desde Jenkins.

La verificacion cubre la pipeline, el analisis de SonarQube, la ejecucion del
agente, la sincronizacion de comentarios, la generacion de
`codeguardian-results.json`, la revision desde Visual Studio Code y la
observabilidad.
